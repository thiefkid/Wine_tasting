# Great Wines of the World HK 2026: tasting planner

Plan a route through James Suckling's Great Wines of the World, Hong Kong (30 Oct 2026). Every wine from the official cheat sheet is ranked by estimated price, fame and JS score, with a tasting order, floor map and checklist.

**Live:** https://thiefkid.github.io/Wine_tasting/

Each person's plan, ticks and notes are saved in their own browser.

## Files
- `planner.html` is the source (also published as a Claude Artifact).
- `index.html` is generated from it for GitHub Pages: run `./build.sh` after editing `planner.html`.

Prices are estimates for ranking only; JS points come from the event's wine list.
